### 三步开始用

1. 下载 `StickyDesk-v1.0.2-win64.zip`，**解压到一个空文件夹**（例如 `D:\StickyDesk`）；
2. 双击文件夹里的 `StickyDesk-1.0.2.exe`，预置的便签就会出现在桌面；
3. 之后所有操作都在**任务栏右下角通知区的便签图标**里：右键出菜单，双击显示全部便签。

> `exe` 与 `stickydesk.db` 必须放在同一个文件夹，程序只认自己旁边的数据。
> 请不要放在 `C:\Program Files` 这类需要管理员权限才能写入的目录。

> 首次运行 Windows 可能提示「Windows 已保护你的电脑」，这是因为程序没有购买代码签名证书。
> 点 **更多信息 → 仍要运行** 即可。

## 功能

- **便签就贴在桌面上**：不是悬浮窗，而是挂在桌面图层上——按 `Win + D` 显示桌面时它还在，也不会占任务栏、不挡其他程序。
- **点开就写**：点一下便签正文即可就地编辑，没有「编辑」按钮，改完自动保存。标题单独一行，正文滚动时标题不动。
- **待办与到期提醒**：待办主项与子项行首是空心小方块，**编辑时点一下方块就打钩**（再点取消，`Ctrl + D` 同样可用）；给某条待办设到期时间（`Ctrl + Shift + T`），该行后面会挂倒计时标签，到期当天 9:30、提前 1 小时、提前 5 分钟各提醒一次。
- **图片、网址、文件夹都能塞进去**：截图可粘贴进便签；正文里的网址点一下用浏览器打开，本地路径点一下直接打开资源管理器。
- **全局搜索**：托盘菜单「搜索便签」，跨全部便签搜内容，回车跳到那一行。
- **八种配色**：黄 / 绿 / 粉 / 紫 / 蓝 / 灰 / 深色等，便签之间互不影响。
- **换电脑不丢**：托盘「便签迁移」把程序 + 数据打包带走；「分享给好友」把软件打包成可直接发人的 zip（只含模板便签，不含你的数据）。
- **托盘常驻**：开机自启、一键显示/隐藏所有便签、新建便签、导出 Excel、导入 Excel。

## 数据与隐私

- 便签内容本身保存在程序同目录的 `stickydesk.db`（SQLite）里，**不上传、不注册**。
- 删除软件＝删掉整个文件夹；想留数据就只删 exe、保留 `stickydesk.db`。
- 联网只用于拉取标题栏广告文案（公开推广列表，断网则用本地缓存），与便签内容无关。

## 常见问题

**提示「未知发布者」或被杀毒软件拦？**
程序未购买代码签名证书，属于正常现象。点「更多信息 → 仍要运行」，或把解压目录加入杀毒软件白名单。

**便签不见了？**
双击任务栏通知区的便签图标即可显示全部；图标可能被折叠在 `^` 里。若连图标都没有，可能是程序没启动，重新双击 exe。

**能把便签放到别的电脑吗？**
托盘菜单「便签迁移」导出迁移包，在新电脑解压双击即可，数据完全一致。

**卸载怎么卸？**
绿色版：先退出程序（托盘菜单「退出软件」），再删掉整个文件夹。开机自启项可在托盘菜单里先关掉。

**界面能换语言吗？**
界面跟随 Windows 显示语言：中文系统显示中文，其它语言自动切换为英文。想强行指定可以设环境变量 `STICKYDESK_LANG=zh` 或 `STICKYDESK_LANG=en` 后启动。
